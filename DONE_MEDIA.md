# Реализованные media leaf-задачи FE-41…47

Эти пункты входят в [общий список реализованного](DONE.md). Source-тесты и сборка не закрывают физические QA-06/07.

- [x] **FE-41 · T-030:** выбранные 720p/1080p × 30/60 передаются не только capture, но и `screenShareEncoding.maxFramerate`; устранён LiveKit default 15 FPS. Sender FPS теперь показывается только из sender stats, а не из capture settings. [Регрессия](evidence/media/screen-share-encoder-fps-2026-09-26-001.json) и 574 интегрированных frontend-теста/сборка PASS; фактический FPS зрителя остаётся QA-07.
- [x] **FE-42 · T-022:** персональная громкость участника не сбрасывается на 100% при недоступном localStorage или ошибке загрузки аккаунта; fallback живёт в памяти текущего аккаунта без переноса настроек между аккаунтами. [Регрессия](evidence/voice-participant-volume/2026-09-26.json) и frontend suite/build PASS; слышимость на двух клиентах остаётся QA-06.
- [x] **FE-43 · T-030:** зритель отдельно выключает/включает звук выбранной трансляции без отключения голоса; 0% восстанавливается кнопкой, поздняя аудиодорожка подключается после выбора, Web Audio source повторно используется при переключении. [Регрессия](evidence/media/screen-viewer-audio-toggle-2026-09-26-001.json), 574/574 теста и сборка PASS; реальное аудио остаётся QA-06.
- [x] **FE-44 · T-030:** панель выбранной удалённой трансляции показывает decoded FPS, bitrate, потерянные пакеты, пропущенные кадры, jitter и время измерения из LiveKit receiver stats рядом с отдельно измеренным presented FPS. При переключении потока измерения сбрасываются; отсутствующие значения и RTT помечены как недоступные. [Локальное evidence](evidence/media/qa06-qa07-receiver-preflight-2026-09-26-001.json): 578 frontend-тестов и TypeScript/Vite build PASS. Аппаратная приёмка остаётся QA-06/07.
- [x] **FE-45 · T-030:** обновление имени/карточки выбранного stream больше не создаёт новый reader receiver stats и не обнуляет двухточечное окно decoded FPS; замена видеодорожки начинает новое окно. [Регрессия](evidence/media/qa07-viewer-fps-reader-stability-2026-09-26-001.json), общий frontend suite 583/583 и сборка PASS; аппаратный FPS остаётся QA-07.
- [x] **FE-46 · T-022:** запоздалый успех или отказ загрузки прежнего аккаунта не перепривязывает preferences текущей голосовой сессии. Web Audio тест подтвердил gain 0/175/200% одного участника, независимость другого и сохранение при замене voice track. [Регрессия](evidence/voice-participant-volume/2026-09-26-account-race.json), 583/583 и сборка PASS; слышимость остаётся QA-06.
- [x] **FE-47 · T-030:** при замене LiveKit audio/video track зритель отсоединяет ранее прикреплённые дорожки перед подключением новых, сохраняя mute выбранного stream. [Регрессия](evidence/media/screen-viewer-track-replacement-2026-09-26-001.json), 583/583 и сборка PASS; физический звук остаётся QA-06.
