# Фронтенд — только открытые задачи

- [ ] **FE-63 · P1 · T-022/051 — Реальная RNNoise-приёмка и audio-engine parity.** Новая opt-in обработка микрофона добавлена в web и Flutter; ADR-014 намеренно оставляет RNNoise недоступным на macOS/iOS из-за связки VPIO AEC/NS, сохраняя стандартный engine. Проверить на реальных Windows и Android устройствах выбор `off/browser/rnnoise`, фактический engine после обработки кадров, сохранение предпочтения, mute/PTT/deafen, замену устройства, reconnect и bounded fallback при неподдерживаемом формате/ошибке. Для macOS проверить понятное сообщение `platform-aec-ns-coupled` и сохранение AEC. Затем провести согласованное прослушивание русской речи/шума, double-talk, маршрутов USB/Bluetooth и длительного звонка; фиксировать только агрегаты и hardware/build evidence, не PCM. Автоматические browser/native synthetic gates есть, физическая/акустическая приёмка и release readiness остаются `NOT_RUN`/`NO_GO` — [ADR-014](../docs/adr/ADR-014-client-rnnoise.md), [acceptance matrix](../evidence/noise-suppression/2026-10-02-automated-gates.md).
- [x] **FE-62 · P1 · T-054/060 — Восстановить CI после обновления версии приложения.** Устаревшее hardcoded ожидание заменено проверкой относительно `appVersionName`/`appBuildNumber` в `profile_screen_test.dart` (`2372460`); focused и полный Flutter suite прошли (404 теста), а последующий [CI #123](https://github.com/Egkurilov/BOOHTACORD/actions/runs/36991935255) завершился успешно. Исходный [CI #119](https://github.com/Egkurilov/BOOHTACORD/actions/runs/36989324807) был одним дефектом assertion в двух jobs.
- [ ] **FE-61 · P1 · T-030 — Обнаружение чужого стрима на macOS.** Исправлен фильтр, скрывавший активную публикацию без подписанного видеотрека (`autoSubscribe=false`): карточка, навигация и список экранов теперь используют незаглушённую screen-share публикацию. Открытие сохраняет явную подписку и показывает подключение до получения трека. Регрессия воспроизведена тестом до исправления; 347 Flutter tests, analyzer и macOS build проходят — [QA-201](../evidence/flutter/qa201-macos-unsubscribed-screen-discovery-2026-10-01-001.json). Осталась live-проверка появления, просмотра и исчезновения чужого стрима после unpublish.

- [ ] **FE-52 · P1 · T-030/051 — Метрики отправителя Android.** Реализованы ограниченные анонимные `android_native` sender FPS/bitrate/RTT с интервалом 5 секунд; polling прекращается при unpublish, leave, revoke, disconnect и dispose. Формулы/payload/API проходят unit tests, signed APK собран и проверен — [QA-19](../evidence/flutter/qa19-android-sender-metrics-2026-09-27-001.json). Осталось проверить live lifecycle и сопоставить sender с двумя одновременными receiver snapshots в QA-07 на устройстве. Исходный профиль запрашивает максимум 30 FPS; 60 FPS не заявлять без аппаратного прогона.
- [ ] **FE-53 · P1 · T-040/041/044/050 — Просмотр изображения в чате.** Веб TEXT/DM теперь открывает увеличенный viewer через существующие ACL-protected PNG preview endpoints, отдельно скачивает оригинал и обрабатывает loading/retry/unavailable/deleted; native Flutter viewer для TEXT/DM уже имел те же основные состояния — [QA-20](../evidence/flutter/qa20-web-attachment-image-viewer-2026-09-27-001.json). Осталось проверить Escape/focus return, узкие экраны, ACL и визуальный паритет в настоящем браузере на обоих типах чата и на устройствах; preview ограничен сервером PNG до 1024 px. Зависимость DES-09 выполнена.
- [ ] **FE-54 · P1 · T-040/044/050 — Вставка изображения в TEXT.** Clipboard image paste реализован через ту же scoped upload queue, сохраняет соседний clipboard-текст, не отправляет автоматически и использует существующие 10 × 25 MB/error/retry ограничения; attachment-only send поддержан и покрыт тестами — [QA-21](../evidence/flutter/qa21-clipboard-image-paste-2026-09-27-001.json). Осталась browser-проверка paste, смены канала и live 507.
- [ ] **FE-55 · P1 · T-041/044/050 — Вставка изображения в DM.** Clipboard image paste реализован через привязанную к текущему DM upload queue, сохраняет обычный текст, error/retry, limits и attachment-only send поддержаны — [QA-21](../evidence/flutter/qa21-clipboard-image-paste-2026-09-27-001.json). Осталось проверить смену DM и отсутствие утечки, paste, retry и participant-only ACL в настоящем браузере; native Flutter image clipboard остаётся отдельным FE-56.
- [x] **FE-56 · P1 · T-040/041/050 — Native Flutter image clipboard.** Реализовано через нативный `clipboard` plugin: `Ctrl/Cmd+V`, `Shift+Insert`, контекстное меню и явная кнопка читают PNG, вставляют соседний текст и загружают изображение через TEXT/DM-scoped очередь с лимитами, 507/retry и защитой от переключения контекста — [QA-22](../evidence/flutter/qa22-native-clipboard-image-paste-2026-09-27-001.json). macOS и Android debug builds проходят; остаются Windows-native build и фактическая проверка системного clipboard, permission/URI lifetime на всех ОС.
- [ ] **FE-57 · P0 · T-030/051 — Android login IME и screen-share retry.** Login-поля получили постоянные focus nodes, стабильные keys и конфигурацию без автокоррекции/подсказок; Android screen share использует 720p/15 FPS, а незавершённый capture track очищается при ошибке публикации и UI показывает исходное сообщение SDK — [QA-23](../evidence/flutter/qa23-android-ime-screen-share-2026-09-27-001.json). 131 тест, `flutter analyze` и debug APK проходят; подтвердить на Samsung/Gboard ввод нескольких символов без закрытия клавиатуры и запуск/остановку/повтор screen share в комнате с peer.
- [ ] **FE-59 · P0 · T-030 — App-only preview Android.** На Pixel 7 `1.0.18+2026` и `+2027` локальный viewer чёрный при отображении Calculator thumbnail. Сигнал `didFirstFrameRendered` после EGL swap не подтверждает композитинг пикселей — [QA-197](../evidence/flutter/qa197-android-preview-render-event-2026-10-01-001.json). A/B APK `1.0.18+2028` с `EnableImpeller=false` и `SurfaceProducer` также показал чёрный viewer [QA-198](../evidence/flutter/qa198-pixel7-preview-impeller-ab-2026-10-01-001.json). Повторный A/B APK `1.0.18+2029` с тем же opt-out Impeller, но legacy `SurfaceTextureEntry`, дал тот же результат [QA-199](../evidence/flutter/qa199-pixel7-preview-surfacetexture-ab-2026-10-01-001.json). В `SurfaceTextureRenderer` обнаружен риск гонки: EGL-release старой поверхности асинхронный, а backing `SurfaceProducer` менялся до подтверждения release. Добавлен барьер и unit-тест; Android plugin tests и release APK `1.0.18+2030` собраны, но Pixel сейчас не подключён, поэтому исправление ещё не подтверждено на устройстве — [QA-200](../evidence/flutter/qa200-android-screen-preview-egl-resize-barrier-2026-10-01-001.json). Следующий шаг — проверить Calculator app-only и full-display preview на Pixel, затем sender/receiver counters с paired viewer. Ранее тесты делались с выключенным микрофоном и завершались остановкой screen share и выходом из SHARE_TEST; парный viewer не подключался. Задача остаётся открытой.
- [ ] **FE-60 · P2 — Диагностика клиентского OTLP exporter.** Пользовательские логи показывают повторные ошибки batch export и 5-секундный timeout. Flutter теперь включает только HTTP status code в ошибку non-202, не читая/не логируя response body; focused test проверяет код и отсутствие утечки body. Нужно дождаться следующей ошибки на обновлённой сборке и определить причину (session/Origin/rate limit/API→collector/network); exporter best-effort и не должен нарушать голос/стрим — пользовательский прогон ещё не выполнен.
- [x] **FE-58 · P0 · T-030/051 — Качество и picker демонстрации экрана.** Добавлен выбор каждого сочетания `720/1080/1440p × 15/30/60 FPS`, custom picker экранов/окон с live thumbnails, явным выбором, пустым/ошибочным состоянием, retry и описанием bandwidth; Android показывает настроенный системный шаг без desktop source picker — [QA-24](../evidence/flutter/qa24-screen-share-quality-picker-2026-09-27-001.json). Осталось принять thumbnail/source enumeration на macOS и Windows и проверить фактическую encoder/network нагрузку всех профилей на устройствах.
