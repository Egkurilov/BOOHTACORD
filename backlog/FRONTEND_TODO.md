# Фронтенд — только открытые задачи

Срез 01.10.2026. FE-01…51 реализованы; результаты вынесены в [DONE.md](../DONE.md), [DONE_MEDIA.md](../DONE_MEDIA.md), [DONE_RECENT.md](../DONE_RECENT.md) и [архив аудита](../DONE_AUDIT_2026-09-27.md). Открытые frontend-пакеты FE-52…55; FE-57 — Android device acceptance для уже реализованных изменений, включённая в QA-13; FE-59 воспроизводится на текущей Android-сборке: при app-only захвате большой локальный viewer чёрный, хотя карточка показывает thumbnail. Дизайн и browser/device-приёмка остаются отдельными задачами.

- [ ] **FE-52 · P1 · T-030/051 — Метрики отправителя Android.** Реализованы ограниченные анонимные `android_native` sender FPS/bitrate/RTT с интервалом 5 секунд; polling прекращается при unpublish, leave, revoke, disconnect и dispose. Формулы/payload/API проходят unit tests, signed APK собран и проверен — [QA-19](../evidence/flutter/qa19-android-sender-metrics-2026-09-27-001.json). Осталось проверить live lifecycle и сопоставить sender с двумя одновременными receiver snapshots в QA-07 на устройстве. Исходный профиль запрашивает максимум 30 FPS; 60 FPS не заявлять без аппаратного прогона.
- [ ] **FE-53 · P1 · T-040/041/044/050 — Просмотр изображения в чате.** Веб TEXT/DM теперь открывает увеличенный viewer через существующие ACL-protected PNG preview endpoints, отдельно скачивает оригинал и обрабатывает loading/retry/unavailable/deleted; native Flutter viewer для TEXT/DM уже имел те же основные состояния — [QA-20](../evidence/flutter/qa20-web-attachment-image-viewer-2026-09-27-001.json). Осталось проверить Escape/focus return, узкие экраны, ACL и визуальный паритет в настоящем браузере на обоих типах чата и на устройствах; preview ограничен сервером PNG до 1024 px. Зависимость DES-09 выполнена.
- [ ] **FE-54 · P1 · T-040/044/050 — Вставка изображения в TEXT.** Clipboard image paste реализован через ту же scoped upload queue, сохраняет соседний clipboard-текст, не отправляет автоматически и использует существующие 10 × 25 MB/error/retry ограничения; attachment-only send поддержан и покрыт тестами — [QA-21](../evidence/flutter/qa21-clipboard-image-paste-2026-09-27-001.json). Осталась browser-проверка paste, смены канала и live 507.
- [ ] **FE-55 · P1 · T-041/044/050 — Вставка изображения в DM.** Clipboard image paste реализован через привязанную к текущему DM upload queue, сохраняет обычный текст, error/retry, limits и attachment-only send поддержаны — [QA-21](../evidence/flutter/qa21-clipboard-image-paste-2026-09-27-001.json). Осталось проверить смену DM и отсутствие утечки, paste, retry и participant-only ACL в настоящем браузере; native Flutter image clipboard остаётся отдельным FE-56.
- [x] **FE-56 · P1 · T-040/041/050 — Native Flutter image clipboard.** Реализовано через нативный `clipboard` plugin: `Ctrl/Cmd+V`, `Shift+Insert`, контекстное меню и явная кнопка читают PNG, вставляют соседний текст и загружают изображение через TEXT/DM-scoped очередь с лимитами, 507/retry и защитой от переключения контекста — [QA-22](../evidence/flutter/qa22-native-clipboard-image-paste-2026-09-27-001.json). macOS и Android debug builds проходят; остаются Windows-native build и фактическая проверка системного clipboard, permission/URI lifetime на всех ОС.
- [ ] **FE-57 · P0 · T-030/051 — Android login IME и screen-share retry.** Login-поля получили постоянные focus nodes, стабильные keys и конфигурацию без автокоррекции/подсказок; Android screen share использует 720p/15 FPS, а незавершённый capture track очищается при ошибке публикации и UI показывает исходное сообщение SDK — [QA-23](../evidence/flutter/qa23-android-ime-screen-share-2026-09-27-001.json). 131 тест, `flutter analyze` и debug APK проходят; подтвердить на Samsung/Gboard ввод нескольких символов без закрытия клавиатуры и запуск/остановку/повтор screen share в комнате с peer.
- [ ] **FE-59 · P0 · T-030 — App-only preview Android.** На Pixel 7 release APK `1.0.18+2025` воспроизводится чёрный большой локальный viewer при видимой свежей миниатюре Calculator. Код миниатюры вызывает `captureFrame()` на той же локальной видеодорожке, что добавляет временный native `FrameCapturer` sink; значит, хотя бы один кадр дошёл до sink дорожки, но неизвестно, получает ли его `VideoTrackRenderer`, кодирует ли sender непрерывные кадры и показывает ли receiver — [QA-195](../evidence/flutter/qa195-pixel7-app-only-self-preview-2026-10-01-001.json), [QA-191](../evidence/flutter/qa191-pixel7-app-only-screen-preview-2026-10-01-001.json). Инструментировать renderer/sender и проверить с парным web/macOS receiver, добавить регрессионный тест и исправить до закрытия.
- [x] **FE-58 · P0 · T-030/051 — Качество и picker демонстрации экрана.** Добавлен выбор каждого сочетания `720/1080/1440p × 15/30/60 FPS`, custom picker экранов/окон с live thumbnails, явным выбором, пустым/ошибочным состоянием, retry и описанием bandwidth; Android показывает настроенный системный шаг без desktop source picker — [QA-24](../evidence/flutter/qa24-screen-share-quality-picker-2026-09-27-001.json). Осталось принять thumbnail/source enumeration на macOS и Windows и проверить фактическую encoder/network нагрузку всех профилей на устройствах.
