# Проверки, эксплуатация и выпуск

Срез: 25.09.2026. Это отдельные verification-пакеты, а не обещания реализовать уже существующий код заново.
PASS_STATIC/PASS_RUNTIME не равны полному release PASS. Исторические evidence не переписываются.

- [ ] **QA-01 · P1 · T-040/060 — PostgreSQL integration harness.** Локально на PostgreSQL 16.14 изолированные migration-backed тесты покрыли serial/concurrent TEXT retries, attachment link и отрицательный cross-channel reply; полный Go-прогон: 648 PASS, 0 SKIP. GitVerse job теперь поднимает PostgreSQL и машинно отклоняет skip; отсутствие БД локально даёт exit 1 через no-skip gate. Осталось подтвердить новый workflow в trusted GitVerse CI до закрытия задачи. [Evidence](../evidence/qa/qa01-postgres-harness-2026-09-25-001.json). Готово: воспроизводимый PASS локально и в CI, а отсутствие БД явно NOT_RUN/FAIL, никогда не выдаваемое за PASS.

- [ ] **QA-02 · P1 · T-010/012/013/014/020 — Auth/admin concurrency.** Last-admin demote/block race: PostgreSQL 16.14, два конкурентных клиента, по 20 повторов PASS; один активный администратор, только успешное изменение в audit и только заблокированная сессия отозвана. Первичный bootstrap: 20 повторов, ровно один администратор/state/audit. Полный Go-прогон с БД после этих тестов: 657 PASS, 0 SKIP/FAIL; [admin evidence](../evidence/qa/qa02-admin-race-2026-09-25-001.json), [bootstrap evidence](../evidence/qa/qa02-bootstrap-race-2026-09-25-001.json). Осталось отдельными leaf-прогонами проверить login/logout/reset, recovery, role refresh, topology revision и transfer lease; WS закрывается после revoke. POC media — QA-10. Готово: реальный PostgreSQL, два конкурентных клиента, атомарные ограничения и отсутствие secrets в отчёте.

- [ ] **QA-03 · P1 · T-041/044/052 — DM/storage privacy.** PostgreSQL history/search/reply/read cursor и navigation unread/mention counters проверены для caller/peer/стороннего admin: 10 повторов; удалённый body скрыт, поиск удалённого пуст, чужой cursor не создаётся. Реальные PostgreSQL + private-files тесты подтвердили download/preview обоим участникам, отказ стороннему admin/чужой паре/blocked actor/после удаления сообщения и запрет HTML/SVG preview. Полный Go-набор: 663 PASS, 0 SKIP/FAIL; [DM matrix](../evidence/qa/qa03-dm-read-matrix-2026-09-25-001.json), [files](../evidence/qa/qa03-private-file-acl-2026-09-25-001.json). Остались events/notifications, границы 25 000 000/25 000 001 байт и 10/11 файлов, нехватка диска, traversal и cleanup races. Готово: все поверхности соблюдают один participant ACL; реальные storage/DB tests. Зависимости: BE-02/09/10/11/12, FE-16/17.

- [ ] **QA-04 · P1 · T-041/054/060 — Search/migrations/CI.** Локально PostgreSQL 16.14: русский/английский текст, имя только в body, точная фраза, cursor boundaries при равном времени и оба partial GIN plan PASS; пустая и существующая схема с legacy rows, повторный Run PASS. GitVerse release_guard теперь запускает contracts/traceability/Compose/image/deploy проверки; backend job запускает SQL-тесты с no-skip gate, deploy зависит от обоих. Осталось подтвердить trusted GitVerse run: локальный PASS не закрывает CI-gate. [Evidence](../evidence/qa/qa04-search-migrations-ci-2026-09-25-001.json). Готово: trusted pipeline запускает tests до deploy, а failed gate блокирует его.

- [ ] **QA-05 · P1 · T-050 — Authenticated browser E2E.** Пройти auth/reset/logout, две переписки, upload/search, admin/topology, voice navigation/reconnect и оставшиеся FE-задачи на фиксированном candidate. Готово: сценарии с реальным API, keyboard/focus и screenshots 1440/1280/1024 CSS px + zoom 125/150%; screenshot-review именно этого bundle. FE-01…07 реализованы; fixture-данные допустимы только в изолированной тестовой среде.

- [ ] **QA-06 · P1 · T-004 — POC-01.** Отдельные физические Windows и Apple-Silicon macOS presenters, каждый с отдельным observer: движущаяся игра, её звук, разговор и отсутствие цифровой петли. Готово: окружения/версии/устройства и наблюдатель в evidence, compatibility matrix. Evidence preflight от 24.09 — BLOCKED; owner-login и POC topology не считать новой отсутствующей реализацией.

- [ ] **QA-07 · P1 · T-005/030 — POC-02 и низкий FPS.** В существующем плане viewer diagnostics записана жалоба примерно на 1 FPS при macOS → Windows; причина не доказана. Сопоставить sender capture/encode stats и receiver presented/decoded FPS, bitrate/RTT/loss на движущемся контенте для 720p/1080p × 30/60. Готово: измерения до/после и ADR профилей; FE-01 лишь добавляет диагностику. Зависимости: FE-01, QA-06.

- [ ] **QA-08 · P0 · T-007/044 — Запас диска.** [Evidence 25.09](../evidence/capacity/qa08-attachment-volume-2026-09-25-001.json) = BLOCKED: код admission/HTTP 507 проверен, но actual `voice-platform_attachments-data` не доступен из локальной среды. На хосте deployment выполнить read-only `docker volume inspect voice-platform_attachments-data --format '{{.Mountpoint}}'`, затем `df -B1 <mountpoint>` и `findmnt -T <mountpoint>`; сопоставить available/total с `max(2 GiB, 10%)` и текущими in-flight резервациями, сохранить UTC evidence. Исторические 9% root и локальные 31,4% C: не заменяют измерение volume. При недостатке места сохранить HTTP 507, владелец планирует ёмкость; историю не удалять и backups не вводить.

- [ ] **QA-09 · P1 · T-007/060 — Capacity.** Измерить сеть/traffic quota/CPU scheduling, затем профиль 100 voice participants по deployment, до 20 в комнате и согласованный screen-publisher профиль без продуктовой квоты. Готово: hardware/environment, нагрузка и ограничения в evidence; idle CPU/health не считаются capacity. Зависимости: QA-06/07/08, согласованная инфраструктура.

- [ ] **QA-10 · P1 · T-006/022/052 — POC-03.** На pinned LiveKit проверить connected media после kick/ban/logout/reset/session revoke/channel close/transfer, затем replay API и обновлённых SDK credentials. Готово: SFU removal, повторный вход и client reconnect проверены отдельно, revoked доступ не возвращается. Серверный outbox/worker/admission guard уже есть; добавлять новый SFU не нужно.

- [ ] **QA-11 · P1 · T-054 — Контракт доставки.** Действует GitVerse master → тесты → source archive → server build с commit-SHA tags → guarded deploy; есть evidence успешного run #1629339. Исходное ТЗ задаёт main/GHCR, а отдельного delivery ADR нет. Документировать утверждённый путь ADR либо довести поставку до исходного требования; закрыть SBOM/provenance и traceability на CI-host без локального Windows-пути ТЗ. Готово: однозначный trusted pipeline, immutable refs и воспроизводимые checks; существующий успешный deploy не отрицать.

- [ ] **QA-12 · P1 · T-054 — Maintenance/rollback acceptance.** На совместимой схеме проверить warning → запрет новых admissions → migration → rollout → smoke → снятие maintenance; отказ и возврат совместимого image отдельным прогоном. Готово: наблюдатель, сохранённые volumes, две browser sessions и evidence. Guard script и banner готовы; нет auto-down migration/backup. Наличие source commit в master не доказывает успешный rollout.
