# BE-08 Mentions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Persist user-ID mentions atomically with TEXT and DM messages and expose caller-local unread mention counts.

**Architecture:** Add a UUID array to each message row in migration 0035. Each create/edit SQL validates recipients in the same statement as the mutation. History and counters read current rows; soft deletion suppresses visible mentions. Idempotent retries return stored mentions.

**Tech Stack:** Go 1.26, PostgreSQL, pgx, net/http.

---

### Task 2: Atomic persistence

**Files:** `backend/internal/database/migrate/migrations/0035_add_message_mentions.sql` and four mutation `postgres/repository.go` files.

- [ ] Write PostgreSQL integration tests asserting invalid targets do not mutate, idempotent retries preserve mentions, edits replace mentions, and DM cannot mention anyone outside the pair.

- [ ] Run focused PostgreSQL tests through disposable WSL database.
