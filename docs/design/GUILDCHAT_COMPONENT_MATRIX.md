# GuildChat v1 — матрица C-01…C-40

Срез кода: 25.09.2026, ветка `codex/voice-platform-foundation`. Источник имён и состояний — `contracts/components.json` внутри исходного `GuildChat_Design_System_v1.0.zip` (40 записей); текстовый обзор — [Design System](GuildChat_Design_System_v1.0.md). Матрица фиксирует соответствие исходного контракта текущему коду, а не browser/pixel PASS. Колонка «проверить» указывает задачу-владельца оставшегося отклонения или приёмки.

Reference внутри исходного архива: **B** `references/02-light-board.png` и `reference/screenshots/components-1440.png`; **D** `references/01-dark.png`; **C** `reference/screenshots/chat-1440.png`; **M** `reference/screenshots/chat-640.png`; **V** `reference/screenshots/voice-1440.png`; **S** `reference/screenshots/stream-1440.png`. CSS-ключи: **F** [foundation](../../clients/web/src/design/foundation.css), **H** [shell](../../clients/web/src/design/shell.css), **N** [navigation](../../clients/web/src/design/navigation.css), **T** [conversation](../../clients/web/src/design/conversation.css), **V** [voice](../../clients/web/src/design/voice.css), **A** [authentication](../../clients/web/src/design/authentication.css), **G** [settings](../../clients/web/src/design/settings.css), **Q** [search](../../clients/web/src/design/search.css). Общие значения — [tokens](../../clients/web/src/design/tokens.css).

Для ≥1440 CSS px принято исключение [ADR-009](../adr/ADR-009-png-shell-geometry.md): рамка 0, nav 280, aside TEXT 248. Оно заменяет исходный текстовый профиль 24/312/312; отклонение заново не открывается. Для voice и выбранного stream действует wide stage [ADR-008](../adr/ADR-008-voice-stage-layout.md), с участниками в drawer. Оба решения ждут screenshot-проверки DES-06/08.
