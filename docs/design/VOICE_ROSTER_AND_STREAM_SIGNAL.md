# Голосовые комнаты: состав до входа и сигнал трансляции

Решение для авторизованного участника одной гильдии. Список каналов показывает текущий состав каждой доступной VOICE-комнаты до подключения; выбранная комната повторяет список над кнопками входа. Имя берётся из действующего профиля, без приписки «· вы». Число в навигации означает подключённых участников, а не говорящих в эту секунду.

## Состояния

| Состояние | Навигация и prejoin |
| --- | --- |
| Участники подключены | Число, аватары и имена; выбранная комната показывает полный список. |
| Никого нет | В prejoin явное «Пока никого нет»; навигация остаётся компактной. |
| Snapshot загружается | «Проверяем, кто сейчас в комнате…» без выдуманного нуля. |
| Media snapshot недоступен | «Не удалось обновить состав комнаты»; обновление повторяется. Старый список не показывается как текущий. |
| Участник показывает экран | Выделенная иконка экрана и «Идёт трансляция» в prejoin; компактный индикатор в навигации. |

Сервер отдаёт состав только по действующей session/ACL, активному LiveKit-подключению и неотозванному voice lease. Клиент обновляет один общий snapshot после входа, восстановления realtime и периодически; ответ не кешируется. Сам факт voice lease не считается доказательством присутствия. Список не раскрывает DM или содержимое трансляции и не подменяет приёмку на двух media-клиентах.

У уже подключённого участника новое **чужое** screen share получает заметный индикатор в карточке и временное объявление в dock. Короткий звуковой сигнал можно выключить в dock; собственный stream, первоначальная загрузка, повторная подписка и reconnect не звучат повторно. Звук подчиняется политике браузера: если воспроизведение запрещено, текстовый и визуальный сигнал остаются. Индикатор не опирается только на цвет; доступное имя события и состояние кнопки доступны клавиатуре и screen reader.

Приёмка: два аккаунта, один остаётся вне voice и видит join/leave/share другого без входа; недоступный LiveKit не выглядит пустой комнатой; после logout старый roster очищен; собственное имя без суффикса; при первом чужом stream виден индикатор и один сигнал при включённой настройке, а refresh/reconnect не дублируют его. Фактическую слышимость и screen-reader произнесение проверяют DES-04/05 и QA-06/07 на реальных клиентах.
