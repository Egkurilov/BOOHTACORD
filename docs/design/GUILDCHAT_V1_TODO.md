# GuildChat v1 — только открытые задачи дизайна

Срез 27.09.2026. Источники: [дизайн-пакет](GuildChat_Design_System_v1.0.md), [матрица компонентов](GUILDCHAT_COMPONENT_MATRIX.md), [история](GUILDCHAT_V1_STATUS.md). Завершённые DES-01 и части других пакетов вынесены в [DONE.md](../../DONE.md) и [архив аудита](../../DONE_AUDIT_2026-09-27.md). В каждом пункте ниже указан критерий, который ещё не выполнен; source-тесты не заменяют visual/screen-reader приёмку.

- [ ] **DES-02 · P1 · T-040/041/044/050 — Переписка.** На одном фиксированном candidate проверить TEXT/DM с длинными именами, файлом, reply/mention, историей, ошибками upload и пустым состоянием через нативный OS chooser. Пройти keyboard и screen reader, настоящий page zoom 125/150% и сравнение одинаковых screenshot-состояний на 320/640/1440 px. Отдельно принять viewer изображения и вставку из clipboard по DES-09. Результаты с device/browser/version и SHA сохранить в evidence.
- [ ] **DES-03 · P1 · T-010/012/014/020/050 — Аккаунт и администрирование.** Проверить оставшиеся loading/denied/error/success состояния регистрации, reset-link, profile, members, audit и admin topology; clipboard-permission для reset-link, keyboard/screen-reader и мобильную раскладку. Для закрытия VOICE подтвердить connected-media finalization, а не только запрет нового входа. Сохранить visual/AX evidence.
- [ ] **DES-04 · P1 · T-022/030/050 — Voice и stream.** На реальных media-клиентах сверить disconnected/listener/joining/connected/reconnecting, mute/deafen/PTT, transfer/kick/closed и 1/6/20 участников; проверить ник, roster до входа, «ЭФИР»/звук начала, no stream/first frame/ended/no audio/permission denied. Зафиксировать visual/AX/audio результаты без заявления неподтверждённого FPS. Зависимости: QA-06/07/10.
- [ ] **DES-05 · P1 · T-050 — Keyboard/focus.** Полный проход Tab/Shift+Tab/Enter/Escape и screen reader для auth/reset, TEXT/DM и нового image viewer, поиска, admin/profile/audio drawer, voice/PTT и вложенных popover; проверить focus trap, announcements и возврат к trigger после закрытия. Зависимость: QA-05.
- [ ] **DES-06 · P1 · T-050 — Responsive и zoom.** Проверить voice/viewer, image viewer, drawers и dock/footer на 320/640/883/1024/1280/1440 CSS px с keyboard, затем настоящий browser zoom 125/150%; исключить обрезанные controls и горизонтальную прокрутку. CSS viewport override не считается проверкой zoom.
- [ ] **DES-07 · P2 · T-050 — Тексты и семантика.** Сверить русские сообщения/ошибки и фактическое озвучивание в браузере для auth, chat/attachments, image viewer, admin, voice и stream; различать download, просмотр, отсутствие audio track и действие отключения звука. Подтвердить в реальном media-сценарии QA-07.
- [ ] **DES-08 · P1 · T-050 — Screenshot parity.** Сохранить reproducible reference/candidate PNG одного содержимого, scroll, hover/focus, ревизии и viewport для TEXT/DM, image viewer, connected voice и selected stream на 320/640/1024/1440 px; сравнить, исправить отклонения и повторить capture. Утвердить отсутствующие matching-state reference для 320/1024; прежние synthetic/разные состояния не закрывают gate.
- [ ] **DES-09 · P1 · T-040/041/044/050 — Изображения в переписке.** Утвердить TEXT/DM состояния миниатюры, увеличенного защищённого preview до 1024 px, отдельной кнопки скачивания оригинала, loading/error/403/deleted, пустого/длинного alt и клавиатурного modal dialog с Escape и возвратом фокуса. Для clipboard paste определить предпросмотр до отправки, image-only сообщение, текст рядом с изображением, лимиты, retry и поведение при смене чата; проверить mobile 320 px и screen reader. Передать макет/acceptance FE-53…55 и QA-05.

Связь с исходными DS-T01…12 и подтверждённые локальные результаты сохранены в [GUILDCHAT_V1_STATUS.md](GUILDCHAT_V1_STATUS.md). Полная browser/media приёмка проходит по [VERIFICATION_TODO.md](../../backlog/VERIFICATION_TODO.md).
