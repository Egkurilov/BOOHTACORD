# Словарь интерфейса и состояний v1

Срез 25.09.2026. Этот словарь применяет утверждённое ТЗ и GuildChat Design System v1 к текущим русским подписям. Он не утверждает новый бренд или результаты media POC.

## Названия

| Контекст | Название | Правило |
| --- | --- | --- |
| Репозиторий и рабочий backlog | BOOHTACORD | Имя проекта; не переносить автоматически на экран входа. |
| Дизайн-пакет, tokens и компоненты | GuildChat v1 | Рабочее имя библиотеки из reference board, не конечный бренд. |
| Заголовок вкладки, вход, desktop notifications | Voice Platform | Текущее рабочее имя UI; одинаковое в этих трёх местах до решения владельца о бренде. |
| Сущность продукта | Гильдия | В deployment ровно одна гильдия, без server switcher. |

## Голос и демонстрация

| Условие | Пользовательский текст | Что он означает |
| --- | --- | --- |
| Нет голосовой сессии | «Голос не подключён» | Не обещает состав участников или media. |
| Подключение восстанавливается | «Восстанавливаем голосовое соединение» | Ручной выход прекращает ожидание. |
| Deafen включён | «Удалённый звук и микрофон выключены» | Показ экрана этой кнопкой не отключается; если дорожка есть, она не воспроизводится локально. |
| Свой экран выбран | «Предпросмотр собственного экрана без звука» | Локальный видеопросмотр заглушён. |
| У демонстрации нет audio track | «У демонстрации нет аудиодорожки» | Не приписывать дорожке игровой источник. |
| Audio track есть и deafen включён | «Удалённый звук выключен; аудиодорожка сейчас не воспроизводится» | Наличие дорожки не обещает слышимость. |
| Audio track есть, но нет личной регулировки | «Аудиодорожка есть; личная настройка громкости недоступна» | Не обещает слышимый звук или звук игры. |
| Audio track есть и регулировка доступна | «Громкость аудиодорожки» | Управляет дорожкой, а не гарантирует её содержимое. |
| Viewer открыт без deafen | «Звук участников управляется отдельно от демонстрации» | Не обещает, что голоса существуют или слышны. |
| Нет свежей диагностики | «Нет свежих данных» | Целевой FPS не подменяет фактический; до измерения не показывать достигнутый профиль. |

Наличие audio track — только метаданные публикации LiveKit. Слышимость, игра, отсутствие эха и фактический FPS требуют наблюдений QA-07; viewer не объявляет их доказанными.

## Аккаунт, навигация, уведомления

| Контекст | Правило |
| --- | --- |
| Экран входа | «На своём сервере · одна гильдия»; действия «Войти», «Регистрация», «Создать аккаунт». |
| Заголовок комнаты | «Голосовой канал» и число участников из текущего состояния, без оценки качества звука. |
| TEXT/DM | «Сообщение», «Личное сообщение», «Канал»; удалённое/недоступное и ошибка загрузки — разные состояния. |
| Browser notification | Только «Новое личное сообщение» или «Новое сообщение в канале» и счётчик; текст/автор DM не выводятся. |
| Ошибка действия | Называет неудачное действие и доступное восстановление; не обещает успех до ответа сервера. |

Auth/header/viewer/notifications сверены по `AuthenticationLanding.vue`, `ConversationPane.vue`, `ScreenViewer.vue`, `VoiceDock.vue`, `notification_delivery.ts` и `notification_policy.ts`. Визуальная, screen-reader и физическая media-приёмка остаются DES-04/05/08 и QA-05/07.
