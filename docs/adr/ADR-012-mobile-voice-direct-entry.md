# ADR-012: прямой вход в голосовой канал на телефоне

Статус: принято по запросу владельца продукта, 2026-09-28.

## Контекст

Мобильный Flutter-клиент открывал экран подготовки после выбора голосового канала. Если сервер находил прежний активный lease, клиент дополнительно требовал нажать «Перенести подключение». Это мешало повторному входу в ранее посещённую комнату.

## Решение

Нажатие на конкретный голосовой канал в мобильной навигации сразу запускает подключение. При `ACTIVE_VOICE_LEASE` клиент делает ровно одну повторную попытку с `transfer: true`. Отдельное подтверждение переноса не показывается. Выбор фильтра «Голос» сам по себе не подключает к комнате. Повторный выбор уже подключённой комнаты не создаёт новый lease. При другой ошибке входа переноса нет; ошибка остаётся видимой, а повторный вход доступен пользователю.

Серверный контракт и ограничение одного активного lease на аккаунт не меняются. Web-клиент сохраняет отдельное подтверждение. Перенос может завершить прежнее голосовое соединение на другом устройстве; это следствие явно выбранного пользователем канала.

## Проверка

Flutter widget-тест проверяет запуск входа из мобильной шторки. State-тесты проверяют одну попытку переноса только после `ACTIVE_VOICE_LEASE` и отсутствие переноса при других ошибках. Реальное переключение двух устройств остаётся пунктом iOS-приёмки.
