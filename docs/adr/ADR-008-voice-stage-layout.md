# ADR-008: широкая область голоса и демонстрации

- Статус: принято для визуальной реализации, ожидает браузерной приёмки
- Дата: 2026-09-24
- Основание: запрос владельца довести интерфейс 1:1 до приложенных референсов

## Контекст

В архиве GuildChat `reference/screenshots/voice-1440.png` и `stream-1440.png` показывают голосовую комнату и демонстрацию с широкой центральной областью до правой границы shell. При этом текстовый layout profile и HTML-preview предусматривают постоянную правую колонку участников на широком экране. Реализация следовала текстовому контракту; после подключения комната и видеохолст из-за этого заметно уже PNG.

## Решение

При выборе голосового канала, включая просмотр выбранной демонстрации, desktop shell отдаёт центральной области ширину между навигацией и правой границей. Список участников остаётся доступным через существующую кнопку в шапке и открывается поверх содержимого как drawer. Текстовые каналы сохраняют постоянную правую колонку. На ширине менее 1280 CSS px действуют существующие правила drawer; VoiceDock и голосовое соединение не меняются.

Это точечное визуальное исключение из общей трёхколоночной схемы. Источником списка по-прежнему служат подтверждённые сервером/LiveKit участники, без фиктивных данных.

## Последствия и проверка

Центральная область получает место для читаемой сетки карточек и выбранного видео. Доступ к списку участников требует одного действия, но кнопка остаётся видимой и имеет `aria-controls`/`aria-expanded`. Результат не объявляется пиксельно принятым до скриншотов авторизованного подключённого состояния при 1440/1280/1024 CSS px и zoom 125/150%.
