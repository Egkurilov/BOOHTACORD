# ADR-009: геометрия desktop shell по PNG-референсу

- Статус: принято для визуальной реализации, ожидает браузерной приёмки
- Дата: 2026-09-24
- Основание: требование владельца довести интерфейс до визуального соответствия приложенному референсу

## Контекст

Текстовый раздел «Сетка экранов» в GuildChat Design System v1.0 задаёт для 1440 CSS px рамку 24 px, навигацию 312 px и панель участников 312 px. Однако приложенные `chat-1440.png`, `voice-1440.png` и `stream-1440.png` показывают каркас без внешней рамки: навигация занимает x=0…280 px, в чате панель участников — x=1192…1440 px. От прежних значений голосовые карточки даже в широкой области получались примерно по 162 px вместо примерно 175 px на PNG.

Верхние 52 px PNG заняты навигацией автономного HTML-превью («Чат», «Голос», «Стрим», «Компоненты»), а не элементом продуктового приложения. Синтетические участники, сообщения и показанные значения качества также не являются данными пользователя.

## Решение

На ширине от 1440 CSS px продукционная область приложения следует горизонтальной композиции PNG: внешняя рамка 0 px, навигация 280 px, постоянная правая колонка текстового канала 248 px с горизонтальным отступом содержимого 16 px. Центральная область чата при ровно 1440 px получает 912 px, голосовая комната по ADR-008 — 1160 px. Шесть карточек с промежутком 12 px и внутренними отступами комнаты 24 px получают около 175 px каждая.

Это осознанное исключение из текстового профиля 24/312/312. Правила 1280–1439, 1024–1279 и мобильного drawer не меняются. Демонстрационная верхняя панель превью, фиктивные данные и измеренные media-показатели не переносятся в приложение.

## Последствия и проверка

Каркас чата, голоса и стрима ближе к PNG по горизонтали, но пиксельное совпадение ещё не доказано. Высота шапки, положение VoiceDock и прочие элементы проверяются отдельными задачами. Тесты закрепляют размеры shell и доступную ширину карточек; для окончательной приёмки нужны скриншоты авторизованной подключённой комнаты и чата при 1440/1280/1024 CSS px и zoom 125/150% без раскрытия приватного контента.
