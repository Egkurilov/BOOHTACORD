# Быстрые клавиши голосового канала (#106)

Настройки → Аудио → Быстрые клавиши: назначение, очистка отдельного действия
и сброс обоих назначений. Escape отменяет запись, Backspace/Delete очищают,
Tab завершает запись и продолжает навигацию. Например, Ctrl+Alt+M и Ctrl+Alt+D.
Назначения хранятся локально отдельно для каждого аккаунта, не на сервере.
Сброс не меняет устройства, обработку аудио или PTT. Ошибка записи оставляет
прежнее назначение и показывает ошибку.

## Область действия

- Vue Web: только видимая вкладка с фокусом. При потере фокуса, смене подключения
  или назначений незавершённая команда не публикует устаревший статус.
- Windows Flutter: только активное окно; глобальных системных hotkeys нет.
- Flutter Android/iOS: раздел появляется после аппаратного key-down в активном
  приложении. При уходе в фон обнаружение сбрасывается. До этого раздел скрыт.
  Flutter не предоставляет универсальный сигнал отсоединения клавиатуры:
  отключение без ухода в фон требует проверки на реальном устройстве.
  Существующий touch PTT сохраняется.
- Ввод текста, IME, диалоги и интерактивные контролы не переключают голос.
  Удержание основной клавиши не повторяет команду. Пока переключение выполняется,
  следующее сочетание игнорируется.

Новые Flutter назначения используют physical USB HID code + modifiers;
Vue использует KeyboardEvent.code + modifiers. Метки одинаковые, например
Ctrl+Alt+M. Старые Flutter назначения с logical keyId остаются читаемыми;
для независимости от раскладки их нужно назначить заново.

## Конфликты и голосовые ограничения

Не принимаются одиночные буквы/цифры, modifier-only, управляющие клавиши записи,
Space/F5/F11/F12, неизвестные физические коды, совпадения с другим действием
или PTT. Ctrl/Meta+K с дополнительными модификаторами зарезервировано для поиска.
Общая политика исключает распространённые browser/OS сочетания: Ctrl/Meta
без Alt с R/W/T/N/L/P/F/O/S/D/Q/H/J/U/B/A/C/X/V/Z/E/I/Tab, Shift+M;
Meta без Alt с буквами/цифрами/стрелками; Alt+F4/Tab/Space и Ctrl+Alt+Delete.
Политика консервативная и не гарантирует перехват системных комбинаций.

Команда микрофона не включает capture при listener-only, PTT, deafened,
ошибке доступа к микрофону или reconnect. Ручное включение микрофона остаётся
в существующем контроллере и может вывести пользователя из listener.
Deafen вызывает существующую последовательность mute/output-disable/restore.
Отдельного источника состояния голоса нет. Результат виден в live status
области рабочего пространства. Сочетания и пользовательский ввод не логируются.
